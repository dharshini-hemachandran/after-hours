# Dharshini Hemachandran — portfolio
A digital institution of ideas: a hand-built static site (HTML, CSS, JS, GSAP). No build step.

- `index.html` · `visibility-trap/` · `campus-connect/` — three real routes, relative paths (works under the GitHub Pages sub-path).
- `assets/css`, `assets/js/main.js`, `assets/fonts` (self-hosted), `assets/js/vendor` (GSAP).
- Deploy: push to `main`; the Pages workflow publishes the repository root. Preview locally with `python3 -m http.server`.
- Motion honours `prefers-reduced-motion`; all content is available without JavaScript animation.
- Licences and photo sources: see `ASSETS.md`.
